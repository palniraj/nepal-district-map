# Changelog

## 1.0.0 (2025-05-04)

Initial release.

- Interactive SVG map of Nepal with all 77 districts and 7 provinces
- Accurate Darchula boundary including Limpiyadhura-Kalapani-Lipulekh territory
- Three color modes: `province`, `flat`, and `data` (choropleth)
- Province filtering with `selectedProvince` prop
- Hover tooltips with custom `renderTooltip` support
- Click and hover event handlers
- Custom color scales via `colorScale` prop
- District labels with configurable font size, color, and short names
- Raw data export via `nepal-district-map/data` entry point
- Full TypeScript support
- Zero runtime dependencies (React as peer dependency)
- ESM and CJS dual-format builds
